# 4×4 〇×ゲーム

ブラウザで遊べる、4×4マスの〇×ゲームです。縦・横・斜めのいずれかに3つ並べたら勝ちになります。コンピューターAIとの対戦ができます。

## 特徴

- **4×4の盤面**で、3つ並べたら勝利
- プレイヤーとコンピューターの**先手・後手を選択**可能
- **強いAI**を実装
  - アルファベータ枝刈り付きミニマックス法で約6手先まで読み切り
  - 即勝ち・即ブロックを優先
  - 低確率で別の手も選ぶため、毎回同じ展開になりにくい
- 勝利した3マスをハイライト表示
- 引き分け判定、ゲームのリスタートに対応
- スマートフォンでも遊べるレスポンシブデザイン

## 遊び方

1. `index.html` をブラウザで開きます。
2. 「先手（×）」または「後手（○）」を選びます。
3. 空きマスをクリックして石を置きます。
4. 縦・横・斜めに3つ並べると勝ちです。
5. 「新しいゲーム」でいつでも最初からやり直せます。

先手・後手を切り替えると、自動的に新しいゲームが始まります。

## AIについて

コンピューターは以下の流れで着手します。

1. すぐに勝てるマスがあれば、そこに置く
2. 相手が次に勝てるマスがあれば、そこをブロックする
3. それ以外はミニマックス法で数手先を読み、最も有利な手を選ぶ
